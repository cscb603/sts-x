STS-X v3.2.0（v5.1 毕业版）使用说明
================================

【这是什么】
STS-X 是「给 AI 用的代码+文件搜索引擎」。帮你（或 AI 助手）在项目代码里快速找到
函数、类、文件——搜得准、回得快、输出省。单文件、零依赖、免安装。

【怎么用（命令行）】

  # 1. 把 sts-x 放到 PATH（Mac: /usr/local/bin/，Win: 任意目录加 PATH）：
  sts-x ai "处理文件搜索的模块"        # 智能搜索：中文/自然语言直接问
  sts-x ai "McpServer"                # 智能搜索：符号名直接定位
  sts-x search "关键词" -p <项目>      # 精确控制：代码搜索
  sts-x file "文件名" -p <目录>        # 文件搜索：免索引，任何目录都能搜

  # v4/v5 新增能力：
  sts-x search "词" -p <项目> --path-filter cache.rs   # 只搜某一个文件
  sts-x search "词" -p <项目> --sort-recent            # 最近改的文件排前面
  sts-x search "词" -p <项目> --no-hint                # 省 ~200 token/次

【给 AI 用（MCP 服务）】
  方式一（推荐，双平台通用，零依赖）：原生 stdio MCP——在 AI 客户端（WorkBuddy/Claude Desktop 等）的 MCP 配置里填：
    command: <sts-x 绝对路径>   （Win: C:\\tools\\sts-x.exe / Mac: /usr/local/bin/sts-x）
    args: ["mcp", "-p", "<默认项目根>"]
    单二进制直接说 MCP 协议，无需 Python/端口/bridge（工具名 search / file）。
  方式二（Python bridge，旧版）：command: <解压目录>/scripts/sts-x-mcp-bridge
  方式三（手动 HTTP）：终端跑 sts-x serve -p <项目目录> --port 9876，
    客户端连 http://127.0.0.1:9876（/health /tools /search /file）。
  详细配置见 AGENTS.md。

【这版升级了什么】
  1. 中文检索：之前中文查询基本搜不到，现在「文件搜索」「路由」「缓存」等中文词能精确命中
     （适用于代码里有中文注释/文档的项目；纯英文注释项目建议用英文词或符号名搜索）
  2. 搜索结果带绝对路径 + 命中定义行，AI 拿到结果直接能读文件
  3. 搜不到时的智能引导：0 命中会提示「换英文关键词 → 换符号名 → 换文件名」
  4. 新增 --path-filter（单文件圈定）/ --sort-recent（最近优先）/ --no-hint（省 token）
  5. 修复严重 bug：同一文件多个代码块时，搜索结果曾返回错误代码块
  6. v5.1-2 修复：子项目搜索不再误爬到聚合目录根做全量索引（package.json 需 node_modules 配套才算真项目根）
  7. v5.1-3 省流量：有命中不再附 741 字使用指南（实测 expand 省 38%、file 省 27% 流量）；
     输出字段顺序稳定、波动字段移到末尾——兼容 DeepSeek 等 LLM 前缀缓存，重复查询可命中缓存价档
  8. v5.1-3：--max-tokens 预算对中文加权，中文项目预算更准不超量

【常见问题】
  - 第一次搜索会自动建索引（大项目 1 秒内），之后搜索 30 毫秒内返回
  - 项目代码改动后会自动检测并重建索引，不用手动管
  - 想更新版本？直接拿新文件替换旧文件即可，索引自动升级

【支持环境】
  macOS 12+（Apple Silicon / Intel）/ Windows 10/11 64位
