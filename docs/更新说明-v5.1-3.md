## 这版改了什么（省流量 + 缓存友好，为 AI 设计）

### P0-1 有命中砍掉 `_ai_instructions` 指南（最大收益）
- 旧：`build_hint` 在 hits>0 时返回完整 741 字符使用指南 → expand 输出 35%、file 输出 24% 是纯浪费
- 新：hits>0 → 字段省略；仅 0 命中时给中/英自救建议（换英文词→换符号→换文件名）
- 实测：expand 2130→1331 字符（省 38%）、file 2571→1874 字符（省 27%）
- `--no-hint` / `"hint": false` 兼容保留（现在只影响 0 命中自救串，极致省可连它一起省）

### P0-2 波动字段移末尾（前缀缓存友好）
- `search_time_ms` 从 JSON 中部（expand 66%/file 73% 处）移到末尾
- DeepSeek V4 等 LLM 前缀缓存按 token 精确匹配：波动字段位置之后全部缓存失效
- 现在即使 time 波动也只影响尾部，前面 80%+ 内容稳定 → 重复查询命中缓存价档（0.02¥/M）
- 去掉 time 字段后实测输出**字节级稳定** ✅

### P0-3 输出稳定化
- 同参数重复查询输出完全一致（除末尾 time），利于缓存与 AI 解析

### P1-1 `--max-tokens` 中文加权
- 旧：`(chars+1)/2` 统一估算，中文 1 字≈1-1.5 token 但按 0.5 算 → 中文项目预算偏乐观会超量
- 新：ASCII 按 0.5/字符、CJK 按 1.5/字符 → 中文项目预算更准

### P2-1 智能路由确认（不改）
- 符号→locate(top_k=5 行级便宜) / 自然语言→expand(top_k=2+1500 预算) 已是合理自适应，保持

## 怎么装
- Windows：解压本包，`sts-x.exe` 覆盖 `C:\tools\sts-x.exe`（旧版备份 `.bak-v5.1-fixed-20260801`）
- macOS：解压 Mac 包，`sts-x` 放 `/usr/local/bin/`
- MCP：mcp.json 用原生方式 `{"command": "<sts-x路径>", "args": ["mcp", "-p", "<项目根>"]}`
